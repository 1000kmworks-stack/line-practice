# 線の練習

iPad(Apple Pencil)で使うお絵かき練習アプリ。HTML と JavaScript だけでできていて、ビルドは要らない。
イラストアプリを開く気軽さで、すぐ描き始められるのが目標。管理は、そのついでにできる。

## 動き方

- アプリを開くと、すぐ真っ白のキャンバスが出る(上に今のお題が出てるだけ)
- 練習は**毎日1番から順番**に進む。「できた! 次へ」で次の番号へ。とばせない
- 間違えて進んだときは「← 前へ」で1つだけ戻れる(その番号の「できた」記録も取り消される)
- 13番は2回やるので、「1回目」「2回目」と別のステップになる(12番は1ページに2つ描くので1ステップ。全部で14ステップ)
- 13番まで終わったら「おしまい」。そのまま自由に描ける。「もう一度1番から」で2周目もできる
- 途中で閉じても、開き直すと同じ番号・描きかけの絵から再開する
- 日付が変わると、また1番から(前の日の描きかけの絵は消える。残したい絵は「画像で保存」)
- 1・2番は、向きを変えるとキャンバスが白紙に戻る
- ペンの色は、黒・赤・青と、下書き用の薄い水色
- 「≡ 記録」で、連続日数・最近28日のカレンダー・今日の進み具合が見られる

## ファイル

- `index.html` … 画面と見た目(CSS もここ)
- `data.js` … 練習メニュー13個のデータ。文言の修正や練習の追加はここだけ
- `app.js` … キャンバス・順番の管理・記録・保存・バックアップ
- `sw.js` / `manifest.json` / `*.png` … ホーム画面に追加したり、オフラインで開いたりするためのもの

## お手本ガイド

- 3番: 点(毎回ランダム。最大8個で、どの3つも一直線に並ばない)
- 4番: 水平線と、パースの線(毎回ランダム。消失点は画面の外で、出さない)
- 5番: 十字線だけ
- 6番: 円と十字線
- 7・8・10番: 6番に斜め線を2本足したもの

「お手本」「方眼」で出し入れできる。3・4番は「点を打ち直す」「パースの線を変える」で作り直せる。

## パソコンで試す

`index.html` をブラウザで開けば動く。ただしオフライン対応(`sw.js`)は `https://` か `localhost` のときだけ働く。

```bash
python3 -m http.server 8766
```

## iPad で使う

1. GitHub Pages などで公開した URL を、iPad の Safari で開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、アプリのように全画面で動く

## 保存されるもの

すべて、その端末のブラウザの中(localStorage の `line-practice-v1`)に入る。

- 練習した日の記録 … 「≡ 記録」から書き出し・読み込みできる
- 今日の進み具合と描きかけの絵 … 書き出しには入らない

## 見本アニメ

キャンバスの左上に、ペンの動きを小さくくり返し見せる(`demo.js`)。動画ではなく、座標をプログラムで動かしている。
1〜3・5〜11番にあって、4・12・13番にはない。「見本アニメ」ボタンで消せる。1・2番は、選んだ向きに合わせて線の向きが変わる。
